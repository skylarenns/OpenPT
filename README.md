## Open-Source Packet Tracer - work in progress still, most of CCNA things in there

Tired of packet tracer's trash ui and terrible mac support? Voila! OpenPT

Features:
- pt file importer
- `.otp` project export/import with readable JSON packages
- switches
- routers
- commands
- accounts
- server-side storage and local in-browser storage
- Jeopardy
- Quiz mode
- Learn mode
